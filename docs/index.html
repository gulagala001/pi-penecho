📋 pi-penecho 平板安装

一个能在白板上和你互动、有记忆的智能体。电脑 ↔ 平板两端,WiFi 直连,全程不依赖外网。

✅ 当前是电脑直连快速通道——文件从电脑高速下载,不经外网。
ℹ️ 当前是 GitHub 在线通道。若平板与电脑连同一 WiFi,更推荐:平板浏览器打开本页的电脑版 http://<电脑IP>:9288(电脑端启动日志里有显示),下载更快更稳。
1电脑上:下载一个文件,发到平板电脑端操作

在电脑上点下面按钮下载(33MB,发动机已藏在里面),用微信「文件传输助手」/ QQ / 数据线发到平板。

下载白板 app(内含发动机)

2平板上:安装后打开,跟着屏幕走平板端操作

在平板上点开收到的 APK 安装(允许「未知来源」),然后打开「PenEcho 白板」。它会自己:
① 引导你装发动机(系统弹窗,点「允许/安装」)
② 在你家 WiFi 里找到电脑
③ 自动把初始化命令复制好
你只需在打开的 Termux 黑窗口里 长按 → 粘贴 → 回车,等它跑完。

3电脑上:配对 + 模型电脑端操作

平板和电脑连同一个 WiFi。电脑打开控制台 http://localhost:9191:
①「平板配对」卡片 → 点 配对平板(同步文件夹自动建好:你的档案记忆 + 配置)
②「端点 Profile」里确认模型和 key → 保存(几秒内同步到平板)。

✅ 完成

平板打开「PenEcho 白板」,手写提问,智能体板书回答。右下角 ≡ 小球:控制台 / 回白板 / 刷新。

遇到问题?点这里

app 找不到电脑:确认电脑控制台 http://localhost:9191 能打开、两端同一 WiFi,然后点 app 里的「重试寻找」。

平板重启后白板连不上:打开一次 Termux 即可(服务自动恢复)。想全自动可再装 开机自启插件。

用着用着连不上:系统杀了后台。设置 → 应用 → Termux → 电池 → 选「无限制」。

配对没反应:确认两端同一 WiFi;或在电脑上改跑 bash scripts/pair-tablet.sh。
